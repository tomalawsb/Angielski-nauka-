# Kopia i przywracanie danych — wersja 6.6.0

## Utworzenie kopii

1. Otwórz **Więcej → Ustawienia**.
2. Przejdź do sekcji **Kopia i przywracanie danych**.
3. Wybierz **Pobierz kopię JSON**.
4. Przechowuj pobrany plik poza pamięcią przeglądarki, najlepiej również na drugim nośniku.

Przycisk **Pokaż kopię w polu** przygotowuje ten sam zapis jako tekst do ręcznego skopiowania.

## Przywrócenie

1. Wybierz **Wybierz plik JSON** i wskaż kopię utworzoną przez aplikację albo wklej dane do pola tekstowego.
2. Uruchom import.
3. Aplikacja sprawdzi wersję, typy pól, daty, identyfikatory materiałów i stan aktywnej lekcji.
4. Bieżący postęp zostanie zastąpiony dopiero po poprawnym przejściu walidacji.

Maksymalny rozmiar pliku importu wynosi 1 MB. Wersja 6.6.0 obsługuje migrację zapisów ze starszych obsługiwanych wersji, w tym 6.5.0.
