# Dane kursu

Wersja 5.8.5 zawiera dwa niezależne zbiory danych:

- `materials-v5.8.5.js` – zachowana baza 456 materiałów używana przez dotychczasowy trening i powtórki,
- `course-catalog-v5.8.5.js` – katalog poziomów, modułów i lekcji.

Katalog zawiera szkielet pierwszego modułu A1 z 10 lekcjami w statusie `draft`. Lekcje nie są jeszcze widoczne dla użytkownika i nie mają przypisanej treści. Ich publikacja nastąpi po przygotowaniu materiałów pilotażowych.

Model kursu sprawdza identyfikatory materiałów, kolejność lekcji, etapy oraz zasady zaliczenia przed uruchomieniem aplikacji.
